Capas e API

Conecte o TMDB para buscar capas de filmes e séries. Somente o título e o ano são enviados para a busca; os vídeos permanecem no computador.

  1. Crie uma conta no TMDB.
  2. Em Configurações → API, solicite acesso para uso pessoal.
  3. Copie a chave de API ou o token de leitura e cole abaixo.

A credencial fica protegida pelo Windows e não é devolvida à interface. Deixe o campo vazio para mantê-la.

CréditosThis product uses the TMDB API but is not endorsed or certified by TMDB.

Escolher capa

Busque pelo nome e selecione o título correto. Para séries, a capa será aplicada a todos os episódios da mesma série.
